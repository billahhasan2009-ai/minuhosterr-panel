# MINUHoster - Bot Operations Panel

Full-stack Python Flask + HTML/CSS Bot Management Dashboard.

## Features:
- Hacker-level matrix rain login page
- Real-time CPU & Memory usage monitor
- Add, Start, Stop and Manage Telegram bots
- Deployable on Railway, Render, Koyeb or VPS

## Railway Deployment:
1. Upload this zip content to GitHub.
2. Connect repository on Railway.app.
3. Railway automatically detects `Dockerfile` or `Procfile` and runs the panel!
